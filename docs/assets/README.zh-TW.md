## 素材驗證

已審查的 PNG 不含 EXIF 或文字中繼資料區塊。發布檢查會鎖定其 SHA-256 摘要值；若要替換，必須重新進行視覺隱私審查，並有意識地更新摘要值。其他照片、螢幕截圖與模型產物仍不隨附。
