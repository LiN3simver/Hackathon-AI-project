# Private runtime storage

The API creates SQLite databases, inspection images, learning samples, and local dataset manifests here as needed. No records, photos, labels, or fixtures are distributed with this repository.

Use only data you are authorized to process. Keep data and backups outside public source control. Renaming a photograph or hashing its filename does not anonymize its pixels, metadata, or associated records.

See [Data lifecycle](../docs/data-lifecycle.md) for storage boundaries and deletion considerations.
