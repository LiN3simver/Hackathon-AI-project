# 執行階段資料邊界

[English](README.md) | 繁體中文

此目錄是 Guardian 證據流程中的私人執行階段儲存空間。API 會視需要在此建立 SQLite 資料庫、檢查影像、學習樣本與本機資料集清單。作品集提供儲存機制的實作，不隨附營運紀錄、照片、標籤或測試資料。

## 設計目的

資料庫紀錄將上傳檔案連結至檢查工作階段、工作與審核決策。將執行階段資料獨立存放，可讓原始碼展示這些關係，而不必公開檢查證據。

## 本機使用

僅使用您有權處理的資料，並將備份保留在公開版本控制之外。重新命名照片或將檔名雜湊，並不會使其像素、中繼資料或關聯紀錄匿名化。

儲存邊界與刪除注意事項請參閱[資料生命週期](../docs/data-lifecycle.zh-TW.md)。
