# Optional capture references

English | [Traditional Chinese](README.zh-TW.md)

Reference views help communicate the expected capture angle. Guardian's capture guide can use independently created, authorized images configured by the application; this portfolio presents the workflow through source code and diagrams without bundling reference photographs.

## Local customization

Supply authorized images through the application's configuration when demonstrating the capture guide locally. Keep images containing identifiers, people, or private surroundings outside the public repository.

This folder is excluded from version control except for the English and Traditional Chinese README documents.
